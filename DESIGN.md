# Patchnap — Quilt club

Kyle selected Quilt club on November 11, 2026: soft mint, grape ink, and an original sleepy stitched patch mascot. The brand is friendly, playful and dependable. Working line: “Updates handled. Go get some sleep.”

## Concept

The patch has finished its chores and can rest. It appears in the icon, the quiet status header and empty states. Stitches indicate care and completion, never progress. Product states use ordinary words: Up to date, Update available, App open, Excluded, Version held, Needs attention, Unsupported. No invented sleep terminology replaces a standard control.

## Composition and controls

A compact menu bar panel shows the current maintenance state, available updates and next action. The main window has four standard tabs: Overview, Apps, Activity, Settings. Apps use a searchable native list, real app icons, explicit sources and context actions for exclusions and holds. Activity shows actual results only. Settings make background registration and App Store installation authority separate, explicit choices.

Use native controls, focus rings, selection, material, semantic text colors and system appearance. Mint belongs in the status header and mascot; grape in actions and selected controls. State colors always have text. No ornamental animation or moving status when nothing is happening. Honor reduced motion.
